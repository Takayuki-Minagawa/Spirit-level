# Spirit Level - スマホ水平器

スマートフォンの重力加速度センサーを使う、インストール不要の簡易水平器Webアプリです。センサーデータは端末内だけで処理します。

## 特徴

- 📐 **0.1°単位の角度表示**: 横方向と縦方向の傾きを見やすく表示
- 🎯 **安定したリアルタイム表示**: センサーイベント単位のローパスフィルターと円形範囲内の気泡表示
- ⏸️ **HOLD**: 表示中の角度と気泡を固定し、読み取り後に最新値へ復帰
- 🔄 **画面回転に対応**: 縦向き・横向きの表示方向に合わせて角度と気泡を補正
- 💡 **画面の消灯防止**: 任意で有効化でき、計測中・HOLD中に画面を点灯（対応ブラウザのみ）
- 📡 **センサー停止の検出**: 3秒間データが届かなければ明示し、古い計測値での較正を防止
- 🔧 **相対較正**: 任意の面を0°に設定し、絶対水平／相対基準を常時表示
- 📳 **フィードバック**: 非水平から水平になったときに振動と効果音で通知
- 🌓 **テーマ・言語**: ダーク／ライト、日本語／Englishを端末内に保存
- ♿ **アクセシビリティ**: 画面拡大、キーボード操作、読み上げ、低減モーションに対応
- 🔒 **端末内処理**: センサー値を外部サーバーへ送信せず、診断結果はセッション内だけに保存

## ローカル開発

依存パッケージのインストールは不要です。

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

デスクトップでのUI確認は `http://localhost:8000/spirit-level/` を開きます。実際のセンサー確認は、HTTPSで配信したページをセンサー搭載端末から開いてください。

### テスト

```bash
# 全テスト
npm test

# JavaScript構文、全テスト、主要ファイルをまとめて確認
npm run check
```

PRと`main`更新時にはGitHub Actionsでも同じチェックが実行され、成功した場合だけ`main`がGitHub Pagesへデプロイされます。CI・デプロイともにLinux（`ubuntu-latest`）のみを使用します。センサー停止・画面復帰・HOLD・画面回転・Wake Lockの非同期競合は、模擬DOM・センサー・時計を使うテストで検証します。

## 対応環境

| プラットフォーム | 想定動作 |
|---|---|
| iOS Safari | iOS 13以降。開始ボタンからモーション利用を許可 |
| Android Chrome | センサー対応端末で利用可能 |
| デスクトップ | UI確認は可能。通常はモーションセンサー計測不可 |

端末、ブラウザ、ケース、設置面によって測定精度は異なります。精密測定や安全判断には校正済みの専用器具を使用してください。

## 使い方

1. センサー診断画面で利用規約とプライバシーポリシーを確認し、同意します。
2. 「センサーチェック開始」を押します。権限要求が不要な端末では、同意済みの再訪時に自動診断します。
3. iOSでは、ボタン操作に続いて表示されるモーションセンサー権限を許可します。
4. 診断成功後、「水平器画面へ進む」を押します。
5. 気泡と角度表示で傾きを確認します。
6. 読み値を固定したい場合は「HOLD」を押し、同じボタンで計測を再開します。
7. 「ゼロリセット」で現在面を相対0°に設定し、「水平に戻す」で絶対水平へ戻します。
8. 必要に応じて「画面の消灯を防ぐ」をオンにします。点灯維持の状態は設定の下に表示されます。

### センサー停止と画面復帰

有効なセンサー値を3秒以上受信できない場合は停止を表示し、診断画面へのリンクを表示します。通常表示の古い角度は消去します。HOLD中は固定した値を残して「センサー更新待ち」と表示しますが、再開時に古い値を最新値として使いません。有効な値が届けば自動で復帰します。

別タブ・別アプリへ移動するとリスナーと画面点灯を停止します。復帰後は新しいセンサー値を待ち、フィルターを再初期化します。相対較正の基準とHOLD中の値は維持します。診断情報が失われた場合は基準も解除し、再診断へ案内します。

画面点灯はこの画面を開いている間の任意設定で、再読み込み時はオフです。HTTPSとScreen Wake Lock APIに対応するブラウザが必要です。省電力設定などによる拒否・解除時も計測は続けられます。設定をオフ→オンにすると再試行できます。

## 技術詳細

### 角度計算

重力加速度ベクトル `(gx, gy, gz)` から次の式で角度を求めます。

- **ロール角（横方向）**: `atan2(-gx, sqrt(gy² + gz²)) × 180/π`
- **ピッチ角（縦方向）**: `atan2(gy, sqrt(gx² + gz²)) × 180/π`

欠損値、`NaN`、`Infinity`、ゼロベクトルは計測値として採用しません。

計算・較正は端末の座標系に保持し、表示時に`screen.orientation.angle`（従来の`window.orientation`もフォールバック）で画面の座標系へ変換します。HOLD中も端末の固定値から画面回転後の表示へ再投影します。

### ノイズ除去と較正

ローパスフィルター（既定 `α = 0.2`）は、画面描画回数ではなく新しいセンサーイベントを受け取ったときだけ更新します。較正時は最新の未加工重力値へフィルターを再基準化するため、連続して較正してもゼロ点が移動しません。

### 水平判定

ロール角・ピッチ角がともに±0.5°以内で水平へ入り、いったん水平になった後は±0.8°を超えるまで水平状態を維持します。このヒステリシスにより、境界付近で通知が繰り返されるのを抑えます。
